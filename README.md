# orpheus
Título do software: Orpheus :p
Equipe: Ana Julia Petroli Busatto, Daniel Perego Viero, Lucas da Rosa Bergamo e Mateus Pasa de Moraes
  Orpheus é um software de gerenciamento e reprodução de músicas, desenvolvido para proporcionar uma experiência completa de organização e consumo de conteúdo musical. O sistema permite cadastrar e gerenciar artistas, músicas e álbuns, além de possibilitar a reprodução das músicas pelos usuários.A aplicação também oferece recursos de personalização, permitindo que os usuários adicionem músicas aos favoritos e criem suas próprias playlists.
  Suas funcionalidades são diversas, como o cadastro e gerenciamento de músicas, artistas, álbuns, a reprodução de músicas, adição de músicas para os favoritos, a criação e gerenciamento de playlists, a organização das músicas por artistas e álbuns, e a navegação pelo catálogo de músicas, artistas e gêneros.
  As tecnologias utilizadas no desenvolvimento do projeto são:
    Linguagem: Java
    Framework: Não utilizado
    Banco de Dados: Não utilizado
    Ferramentas: Eclipse IDE for Java Developers
  Para executar o projeto, é necessário ter o Java (JDK) instalado no computador e uma IDE compatível com projetos Java. Para o desenvolvimento e execução do projeto, foi utilizado o Eclipse IDE.
  O software pode ser utilizado para organizar e reproduzir um catálogo de músicas.
  A licença do é pública, mas se trata de um projeto acadêmico, sem necessidade de direitos autorais e lincenciatura.

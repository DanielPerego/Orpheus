## Sobre o Projeto

**Orpheus** é um software de gerenciamento e reprodução de músicas, desenvolvido para proporcionar uma experiência completa de organização e consumo de conteúdo musical.

O sistema permite cadastrar e gerenciar **artistas, músicas e álbuns**, além de possibilitar a reprodução das músicas pelos usuários.

A aplicação também oferece recursos de personalização, permitindo que os usuários adicionem músicas aos **favoritos** e criem suas próprias **playlists**.

---

## Funcionalidades

O software possui diversas funcionalidades, incluindo:

-  Cadastro e gerenciamento de músicas
-  Cadastro e gerenciamento de artistas
-  Cadastro e gerenciamento de álbuns
-  Reprodução de músicas
-  Adição de músicas aos favoritos
-  Criação e gerenciamento de playlists
-  Organização das músicas por artistas
-  Organização das músicas por álbuns
-  Organização por gêneros musicais
-  Navegação pelo catálogo de músicas, artistas e gêneros

##  Como Executar

Para executar o projeto, é necessário ter o **Java (JDK)** instalado no computador e uma IDE compatível com projetos Java.

Para o desenvolvimento e execução do projeto, foi utilizado o **Eclipse IDE for Java Developers**.

### Requisitos

- Java JDK instalado
- Eclipse IDE ou outra IDE compatível com Java

Após instalar os requisitos, basta importar o projeto na IDE e executá-lo.

---

## Utilização

O **Orpheus** pode ser utilizado para organizar e reproduzir um catálogo de músicas, permitindo ao usuário navegar pelo conteúdo musical, gerenciar seus favoritos e criar playlists personalizadas.
